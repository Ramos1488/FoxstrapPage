What is Foxstrap?

Foxstrap is not just a launcher, it's a Bloxstrap fork with extended functionality. We focus on providing the user with tools that Roblox hides by default.

Core Goals

  • Performance: Optimization through FFlags.
  • Customization: Full control over game visuals.
  • Usability: Intuitive UI built with C# and XAML.

Frequently asked questions

Will I get banned?

Using Foxstrap is not cheating. We use official FastFlags settings provided by Roblox developers themselves.

Do I need Bloxstrap to run it?

No, Foxstrap works autonomously. It is a completely independent modification.

Modding

Foxstrap has a built-in mod management system that allows you to:

  • Replace the old death sound (Oof).
  • Install custom application icons.
  • Apply custom cursors and fonts.

Engine settings

The engine settings section provides access to powerful FastFlags parameters. This allows for fine-tuning of game rendering.

What can be changed?

  • FPS Limit: Unlock the 60 FPS cap in one click.
  • Rendering API: Switch between Direct3D 11, Vulkan, or OpenGL.
  • Lighting Quality: Enable hidden Future Lighting technologies.
Caution

Incorrect FFlags settings may lead to game crashes.

Privacy policy

We value your privacy. Foxstrap is an open-source project.

Data Collection

Foxstrap does not collect or send your personal data, account passwords, or cookies to third-party servers. All settings are stored locally on your computer.

Transparency

You can always check the project's source code on our GitHub to ensure there is no malicious code.
